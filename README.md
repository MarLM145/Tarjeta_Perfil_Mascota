# Mascota
Aplicación móvil que muestra una mascota, hecho en Android Studio.
## Característcas
* Está aplicación muestra la imagen de una mascota con un texto corto debajo.
* La app está echa en Android Studio usando el lenguaje Kotlin.
* Fue hecha usando compose.
